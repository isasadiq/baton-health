The Core Crisis

The Screening-to-Care Breakdown

A screening program creates value only when an actionable result reaches completed treatment.

30%–50%
Silent Patient Drop-off
Up to half of abnormal screening results (e.g. cervical HPV, colorectal FIT) stall between issuance and confirmed specialist consultation.
#1 Cause
The "Sent = Done" Fallacy
Diagnostic labs send an abnormal PDF and wash their hands. The primary clinic forgets, specialists have 6-month waitlists, and nobody legally owns the next step.
Invisible
Patient Roadblocks
Patients don't miss appointments because they don't care; they skip because of unaddressed real-world friction: fear of diagnosis, inability to afford fees, and zero transit.

The Innovation

The Baton Protocol: Healthcare Relay Architecture

Turning loose asynchronous healthcare referrals into an atomic, stateful custody chain.

🤝
1. One Owner at All Times
A case can never exist in an unowned state. A handoff only counts when the receiving specialist explicitly clicks Accept. If rejected, it bounces back to the care navigator.
⏱️
2. One Clock & Proactive SLAs
Every urgency tier has a deterministic countdown clock. If unacknowledged or unbooked within protocol hours, the case turns red and escalates directly to human coordinators.
🔒
3. No Closing Without Proof
Early or automated closure is cryptographically blocked. A case can strictly only be closed with accepted evidence (biopsy, treatment started, normal repeat) + named clinician signature.

Multi-Stakeholder Surfaces

Tailored, Low-Friction Interfaces

Purpose-built surfaces designed for immediate adoption without training overhead.

📱 Patient Mobile Edge (Calm Check-in)
• Zero Jargon: Minimal, respectful messaging via secure mobile link (never transmits raw medical test numbers over unencrypted text).

• Barrier Identification: Patients tap 1 button to confirm, or select what's stopping them: Cost, Transport, Fear, Work Hours, Confusion.

• Instant Support Matching: Automatically deploys community health vouchers, transit assistance, and 4-hour nurse callbacks.
👨‍⚕️ Clinician 1-Tap Handoff (Zero Login)
• Frictionless Triage: Receiving clinics receive a streamlined card with patient initials, test urgency, and clinical summary.

• 1-Tap Acceptance: Custody locks to the clinic the moment they click Accept.

• Automated Priority Rerouting: If declined (with required reason code) or if the SLA expires, Baton automatically transfers the case to the next specialist clinic in line.

Architecture & Standards

Production-Ready Full Stack Architecture

Built with enterprise clinical governance, auditability, and instant deployment in mind.

Relational State Machine
• PostgreSQL / Supabase Schema: Strict transition checks (`allowed_transitions`), append-only audit trail (`transitions`), and referral attempt ledger.

• Deterministic Urgency: Clear clinical rule tables (HPV 16/18 = Urgent 4h SLA; FIT positive = Priority 12h SLA), avoiding black-box AI risk.
Frontend & Demo Engine
• React 18 + Vite + TypeScript: Fast, accessible UI aligned with custom Figma design system.

• Dual Engine Mode: Embedded reactive TypeScript engine with `localStorage` persistence guarantees 100% demo uptime on Netlify edge.
Backend API & Container
• Node.js Express REST API: Exposes clean endpoints for board views, metrics, and transitions.

• Docker Compose Ready: One-command setup (`docker compose up`) mounts `01_schema.sql` and `02_seed.sql` for enterprise deployments.
